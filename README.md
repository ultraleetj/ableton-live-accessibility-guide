# Ableton Live Basics Guide with Accessibility in Perspective

A community guide to using Ableton Live with a screen reader (NVDA on Windows), aimed at blind and visually impaired producers.

The guide is based on the original "Ableton Live Basics Guide with Accessibility in Perspective" by Vitor Ferreira. It is being corrected, verified and extended with hands-on testing notes from blind Ableton users.

## Contents

- `Vitor_Ferreira_Ableton_Live_Basics_Guide_with_Accessibility_in_Perspective_mod.html`: the guide itself.
- `CONTRIBUTING.md`: how to report corrections and add content.

## Format

The guide is a single plain HTML file with no CSS and no styling. It is meant to be read with a screen reader, not as a designed web page. Each numbered section is an `<h1>`, and shortcut lists use `<ul>` and `<li>`.

## Tested on

Corrections are verified by hand on Ableton Live 12.3 or later (beta builds) on Windows with NVDA. Some shortcuts and behaviors differ from the official documentation and from the stable release. Where tested behavior conflicts with official documentation, the tested behavior is used.

## Status

Sections 3, 4, 5 and 9 are verified. A typo and translation pass has been done across the whole file. Remaining sections are being verified one at a time. Unverified sections may contain errors.
