Ableton Live Basics Guide with Accessibility in Perspective

This is a very basic guide to using Ableton Live from the perspective of someone who is blind or has low vision.
To download and get all the information, visit
www.ableton.com

The sources for its preparation were the Access Ableton podcast
https://pinecast.com/feed/access-ableton
and the Whatsapp group Ableton Access, where hundreds of Ableton users in various countries share their ideas and experiences.
For more detailed information, it is recommended consulting the Ableton manual in English, which describes the accessibility features implemented by the company that develops the program.
Unfortunately, to date, there is no manual in the Portuguese language, so this brief set of notes may be useful in your first contact with this daw.
This manual was created using version 12.3 of Ableton Live.
In the aforementioned podcast, an installation on the Mac system is used, but the vast majority of commands are used on both platforms, and care was taken to adapt the names of the keys whenever necessary. This guide uses Windows key names throughout. On Mac, Alt corresponds to Option, and Control corresponds to Command.


1. The main window:

When you open Ableton, it displays an untitled window.
The program window is divided into two main areas; session view, alt+1, and arrangement view, alt+2.
Arrangement view is the time line. The session view will be described later.
Then there is clip view, alt+3, device view, alt+4 and browser, alt+5.
The browser is used for searching among effects, instruments, etc. It works in a tree structure, and with audio previews while searching.
The device view is accessed when an effect, instrument or plugin is inserted, which in Ableton is called device.
Finally there is the control bar, alt+0, where you define tempo, tone, etc.
When you are in Session view or Arrangement view, you have two zones:
In Session View you have Headers and Slots.
In the Arrangement view you have Headers and timeline.
Whether in Session view or Arrangement view, the Headers area is where you can do things like edit the track list, that is, where you can delete, copy or paste tracks.
In Session view, the slots area is where you can record, insert and configure clips and scenes.
In the Arrangement view, the timeline area is where you can properly record and edit the midi and audio.
To move between headers and slots in Session view, and between Headers and Timeline in Arrangement view, always use the escape key.


2: Basic Settings:

In this part of the program you have several tabs.
To move through them, use the up and down arrows,and to explore the tabs and access the different settings, use the tab key.
At least on Windows, all check boxes are activated with the enter key, or with the arrow keys; the space bar is only for play and stop.
First of all, it is important to press alt+n to the Navigate tab, and there, check the option that says Use Tab Key to Move Focus.
This option can also be selected in the Preferences menu, control+comma, in the View and Input tab.
In that same tab, you can also uncheck the box that says Move Selected Arrangement Clips With Arrow Keys.
This will prevent selected clips from being accidentally moved with the left and right arrow keys.
If you prefer to keep this option activated, you have to make sure that, before you want to move the cursor, you press the escape key to deselect the content; otherwise, you will move it in the timeline, and that may not be what you want at the moment.
you also have Options, alt+o.
There, one of the most important tabs is the Accessibility tab.
The options on this tab are entirely up to taste.
Even so, you can uncheck Speak Menu commands, because if not, it keeps saying play, stop, play, stop.
Another important box to check is Speak Help Text.
Checking this box, when you press alt+shift+control+h, it gives a little useful information about what that function or option allows you to do.
Since you are in Options, you can also check the midi arrangement overview box.
Its function will be explained when the midi editor is discussed.

Now, let's return to preferences with control+comma.
Go to Record, Warp & Launch.
Tab to Count-In.
This option can be useful, as it sets the number of bars that Ableton counts before starting to record.
It can also be left at none, and the program starts recording immediately.
ExclusiveArm. If checked, arms only the selected track. If not, you can set up more than one.
For convenience, it is left checked, so as not to get confused when you have several tracks to work on.
Solo exclusive. It allows you to solo only one track at a time, unlike other daws where multiple tracks can be soloed at the same time. It switches between the two behaviors. Suggests not checking.
A few more tabs until Create Fades on Clip Edges.
Automatically Fade Audio Clips.
If this option is checked, Ableton applies a short fade (approximately 4 milliseconds) to the beginning and end of all new audio clips.
This is used to avoid clicking on the edges of the clip. Suggested to uncheck.

Now let's go to File & Folder.
Uncheck Create Analysis Files.
This way, the program doesn't create those boring analysis files, like Reaper's reapeaks or Sound Forge's sfk, which only take up space and are of no use on today's fastest computers.


3: Session view:

Unlike in arrangement view, tracks are navigated differently. Clips and scenes are placed vertically, tracks are placed and navigated horizontally.
Recording in session view happens in loops, where what you record isn't tied to a fixed timeline position.
Those loops sit inside what Ableton calls scenes. A scene can be as long as you want.
Say you record a piano part in session view: it plays back in a loop. Recordings in session view sync up regardless of their length, meaning whatever you record stays inside that scene even if it isn't quantized.
If you record another track after that, its start always lines up with the start of the previous one.
This is a good way to build up an idea, or to have material ready to trigger live during a performance.
OK, let's record. If you want the metronome, letter o turns it on and off.
Step 1: in session view, select the track and the scene you want, say scene 1, arm the track with c, then press enter to start recording.
To fit the metronome, stop recording before the next bar starts. So for a 2 bar loop, stop before bar 3 begins.
Same idea for midi, except you need an instrument loaded and something to play it with, either a musical keyboard or the computer keyboard.
To use the computer keyboard as an instrument in Ableton, turn it on with m. Z and x shift the octave, the rest of the keys play notes.
If you have a midi controller, you'll get a lot more out of playing with that instead.
Step 2: quantize what you just recorded. Press alt+3 to open the clip detail.
Quantization depends on your zoom level, so once you're in clip view, press control+5 to lock the zoom. It's a toggle, control+5 turns fixed zoom on and off.
Control plus 1 or 2, top row, narrows or widens the grid. Control+3 toggles triplet mode. Control+4 toggles grid snapping.
When it's set the way you want, press control+u to quantize. Control+shift+u nudges the quantization to feel more humanized.
Repeat for whichever tracks need it, all while staying in session view.
The Edit menu also has a Record Quantization feature, which applies the selected quantization as you record instead of afterward. Useful if you already have an idea worked out or know your shortest note duration in advance.
Step 3: say you record another track on another instrument, but its loop ends up longer than the first one. The start is always synced, but to trim the end to match, do this:
A: with the track and scene selected, open clip view with alt+3. A window appears that you explore with tab or shift+tab.
B: set the grid to 1 bar, so you move a full measure at a time.
C: tab or shift+tab to Loop Length, and adjust it with the vertical arrows to the length you want.
You can always preview the result with the space bar, no need to press enter.


3.1: Behavior of clips in Session view:

As already described, clips in session view always play in a loop within the selected scene.
Even so, you can set them to play in sequence, at random, or in other ways.
To do that, select the slot and the clip you want, say the first one, and press alt+shift+p to open the clip preferences menu.
Among the tabs there is one called Clip tabs. Tab through it and you'll find a checkbox called Enable follow actions.
Check that box and keep tabbing, and the follow actions appear: the behaviors you want clips to have toward each other, whether one should play after another, stop, jump to a random clip, and so on.
Whatever you set here decides how the clips behave.


3.2: Recording from Session view to ARRANGEMENT VIEW

Say you've already built out an idea in session view, and set the scenes and clips to play in a row.
Now you want to keep editing, but in arrangement view instead.
With everything set up in session view, press shift+f9.
This arms a track in arrangement view and starts playing your session view content into it for recording.
Each scene gets recorded with its own clips.
Once playback finishes, switch to arrangement view with alt+2 and press f10 to start playback there.
From that point on, everything is ready to edit in arrangement view.


3.3: Take lanes and comping

Here's the most accessible way to work with take lanes, when you've recorded several takes and want to pick the best one.
Say you have a track with an instrumental, and the takes get recorded onto a new audio track.
Step 1: make sure you're on the timeline, select the area you want to record, and loop it with control+l.
Important: adjust the grid settings to match before doing this.
Step 2: press f9 to record, still in arrangement view.
Step 3: press u to unfold the track.
Along with any material already there, the various takes appear, and you can navigate them with the up and down arrows.
If the take lanes still don't show up, press escape to move to the headers area, make sure the tree is expanded, then press right arrow again.
Back on the timeline, the take lanes should now show up vertically.
To listen to a take, select it with the up or down arrows and press t.
For organization, just like with tracks and clips, you can rename takes with control+r.
Step 4: move the cursor to each take, or part of one, select the clips inside it, and copy and paste as needed.
Or skip copy and paste entirely: with the clip selected inside the take you want, press enter. There's no NVDA feedback for this, but it sends that take to the main audio track, into the area where the loop was originally defined.
You can also make time selections within these takes and copy them to any point in the loop area, even if the loop covers the whole song.


4: Basic midi editor operations and keys:

In Ableton, the MIDI editor is the Clip View, accessed with Alt+3.
To hear notes as you interact with them, activate the MIDI Note Editor Preview box, found by exploring the window with Tab or Shift+Tab and also in the Options menu, Alt+O. Also worth activating there: MIDI Arrangement Overdub. Both boxes toggle with Enter.
The Control Bar found by tabbing around the clip editor window also lets you enable Session Record for MIDI overdub, and adjust tempo or time signature in real time via the sliders, either with the vertical arrows or by typing a value directly.
A clip in Ableton is the equivalent of an item in Reaper, or a region in Logic. Whether editing MIDI or audio, you always work with clips. You must always select a clip before you can edit it, MIDI or audio. When you open Clip View, all of the clip content is selected by default, so press Escape first to deselect it. Escape is also a good check that nothing was selected by accident before you edit.
The edit cursor does not follow note preview or MIDI editor position when working from Session or Arrangement View. To sync the playback cursor to your current position in the editor, press Control+Shift+Spacebar, repeat any time you need to reorient or preview your edits.
Entering notes with the computer keyboard: press M to toggle Ableton's own Computer MIDI Keyboard on or off, letting you play notes without a MIDI controller. The home row (a, s, d, f...) act as white keys, the row above (q, w, e, r..) as black keys, starting around C3 (middle C in ableton's terms) by default. Z lowers the octave range, X raises it. C lowers incoming note velocity by 20, V raises it by 20, since the computer keyboard itself is not velocity sensitive.
Inserting notes via step recording: arm the MIDI track, enable the Preview switch in the MIDI editor, and place the insert marker where you want to begin. Hold down the note, either on a MIDI controller or the computer MIDI keyboard, and while still holding it, press Right Arrow to add it. Continue holding and press Right Arrow again to extend that note's length. To remove a note you just added, hold the same key and press Left Arrow instead.
Scale and Fit to Scale: plain Up or Down arrow transposes selected notes by a semitone, disregarding scale entirely. The Fit to Scale button acts on selected notes and snaps any that fall outside the currently selected scale into that scale. The Scale mode checkbox itself is more of a visual aid than an active constraint.
Notes do not extend the clip: a note inserted past the current end point exists in the data but will not play until the clip is manually lengthened to include it.


4.1: Midi editor shortcuts

Tested and confirmed working on my current build, which may be a beta version, so these may not fully match the official documentation for the stable release.
General convention to remember: adding Alt to an arrow-key edit command removes grid snapping, using an increment tied to the current horizontal zoom level instead. This applies both to moving notes and to changing note length.

  • Control+up or down arrow: navigates to and selects the next or previous note, not snapped to grid, this is the main way to select notes for editing. Also targets individual notes within a chord. Adding Shift extends the selection in the direction pressed instead of just moving to it: Up adds a note after the range, later in time, Down adds a note before the range, earlier in time. Good general flow: use Control+up or down to move through and select notes one at a time as you go, or plain left and right arrows to play through and preview notes by grid division without selecting them, useful for quickly finding a passage first. Once notes are selected, the following commands apply their listed effects to that selection.
  • Alt+up or down arrow: changes the velocity value of the selected note.
  • Control+Alt+up or down arrow: changes the probability of the selected note.
  • Shift+Alt+up or down arrow: changes the range or deviation of the note.
  • Up or down arrow, no modifier: transposes selected notes by a semitone, disregarding scale.
  • Shift+up or down arrow: moves the selected notes an octave.
  • Shift+left or right arrow: lengthens or shortens the note, snapped to grid.
  • Left or right arrow, no modifier: moves the selected notes, snapped to grid.
  • Alt+left or right arrow: moves the selected notes, bypassing the grid, in an increment tied to the current horizontal zoom level.
  • Alt+Shift+left or right arrow: lengthens or shortens the note, bypassing the grid, in an increment tied to the current horizontal zoom level.
  • Control+Shift+left or right arrow: adds or removes notes of the same pitch from the current selection.
  • Control+D: duplicates selected notes.
  • Delete: removes selected notes.
  • Control+Spacebar: plays the current selection only, which makes it easy to preview an edit as you make it. With nothing selected, it plays normally from the current bar.
  • Control+F9: sets the clip start marker.
  • Control+F12: sets the clip end marker.
  • Control+F10: sets the loop start.
  • Control+F11: sets the loop end.

Left and right arrow lag: on a direction change, not during continuous movement in the same direction, there is a small offset between the announced position and the actual cursor. Right arrow announces the position you are about to move to, left arrow announces the actual current position. Minor beta quirk, worth reporting if it persists in a later build. Since these arrows are always tied to the grid, widen the grid first if you want to move faster through a clip.
Position format: bar.beat.sixteenth. "2.2.3" means bar 2, beat 2, 3rd sixteenth. 32nd notes append a plus sign, for example "1.1.2+". 64th notes and smaller are not read at all.
Probability and Velocity Deviation, introduced in Live 11: Probability sets the odds a note plays each loop pass, a note at 70% skips roughly 3 times in 10. Velocity Deviation randomizes velocity within a set range on each play. Together they make repetitive patterns feel less mechanical.
Other navigation: Home jumps to the clip start, End to the clip end. Page Up announces the current position but does not appear bound to real navigation. Page Down does nothing.
Chase MIDI Notes, found in the Options menu: lets held notes sound correctly if playback starts partway through them, rather than staying silent until the next note begins.


4.2: Manipulating midi cc data

Once you are inside the clip editor, there are a few shortcuts that activate some views or tabs within the midi editor:
- alt shift 1 is the notes tab, the default one where you can Write, delete, and change the pitch, duration, or velocity of MIDI notes which was covered in section 4 and 4.1.
- alt shift 2 is the envelopes view, the main one regarding this section: You can Draw automation or modulation curves for pitch bend, midi cc, device (effects) parameters, or mixer settings.
- alt shift 3 is the MPE Editor Tab. Here you Edit expressiveness (like per-note pitch bend, pressure, and slide) for MPE-compatible plug-ins.
When you press these shortcuts after opening a midi clip in the editor you will hear nothing, but the view changes things if you tab around and also if you arrow through. The first thing to do in this window is to tab until you find the device selector combo box. You have several options but this will determine what you can control. You will find a list of all the currently inserted fx or devices for the track mixer chains if any, and a MIDI Ctrl item, which is the one we want to control. Once that MIDI Ctrl item is selected, tab around once more to select which midi cc you want to work on. Most of them have names assigned to them, for example cc 64 sustain on/off. Then shift tab twice to be back into the lane for that midi cc. To insert a point you press enter. A breakpoint will be created, so the arrows change function:
- left and right arrows move the place where the breakpoint is placed
- up and down arrows set the value for the point, from 00 to 127. You can also type a value within 0 to 127 and press enter for faster input.
- once done adjusting the point position and value press enter once more. Escape cancels placement.
For example, you can select cc1 for vibrato or modulation, set a point in bar 1 at 0, then move cursor to bar 5 and set it to 127. At this point the program will automatically create a linear curve that progressively goes from 0 to 127 and you can move through points using control left and right arrows for next or previous respectively. When you move through time the current value is announced so you could fill in more points as needed for smoother or more abrupt transitions.


4.3: curve shapes in automation in midi data

So, the last section works fine for something you might want to control most or less gradually over time inside the midi data, but how about exact, square transitions such as sustain on or off? You have two options here depending how the instrument responds to cc64:
The first one is the most straightforward: set sustain to value 65 where you want it on and then 63 where you want it off. These values sit just above and below the actual 64 threshold, so a barely-there change is enough to flip the switch cleanly while still registering as two distinct points rather than one, and adjust from there with the default shape.
The second one is more involved and not as precise, and here we need to take advantage of the route cursor or route navigator to mouse function of your screen reader. For this example, suppose we have selected cc64 sustain and want to make it go on and off more strictly on exact beats.
Note: a couple of crashes turned up while testing this section, applying a shape then inserting a point into a blank envelope, and pressing Control+Delete to remove a whole envelope. Both were intermittent rather than guaranteed, but worth saving your work before experimenting here.
For this, first route the mouse to the position of the cursor and it will highlight the cc lane, then you right click on it. Then you will have the following options near the end of the context menu for the envelope, which is a grid that is 5 long by two tall: 5 options arrowing to the sides, 2 arrowing up and down, so you get 10 unique shapes represented by icons, read by your screen reader, they are:

  • ModulationSine: a smooth wavy squiggle icon, rises and falls in a rounded curve
  • ModulationTriangle: an arch or peak shape, rises to a point then falls, more angular than Sine
  • ModulationSawDown: a downward diagonal, holds near the top then decays with an accelerating curve toward the bottom
  • ModulationSawUp: mirror of SawDown, a rising diagonal
  • ModulationSquare: a stepped, rectangular zigzag icon
  • AutomationShapes/CurveIn: dashed concave arc, curves inward before rising or falling
  • AutomationShapes/CurveOut: dashed convex arc, the opposite curve direction from CurveIn
  • AutomationShapes/SCurveIn: dashed diagonal with an S-bend at the start
  • AutomationShapes/SCurveOut: another dashed diagonal S-bend, mirrored from SCurveIn
  • AutomationShapes/AdrEnvelope: a small asymmetric peak shape

You do still need existing points to work from first, just at wider intervals than the point-by-point method above, for example a point at bar 1 and another at bar 3 with nothing in between. Select the time range spanning those points and apply a shape, and it replaces the straight line between them with its own curve instead of a linear ramp. Note that when making this kind of selection, nothing gets spoken, so you're working somewhat blind until you step through the result afterward with the arrow keys. For Modulation Square specifically, the on-to-off transition always lands exactly at the midpoint of whatever range you select, not wherever you might expect. So to land the drop at a specific bar and beat, select a range where that target point sits exactly halfway between your selection's start and end, apply Square, and repeat for each transition you need.
Two quirks worth knowing before relying on these:
- If a selection's start and end breakpoints hold the same value, the In and Out shapes don't just stay flat as you'd expect, they default to a full 0 to 127 sweep instead. Only matters if your two endpoints happen to match.
- SCurveIn has occasionally inserted an unwanted extra breakpoint of 0 right at the selection start, flattening the whole curve until you manually fix or remove that point.
Given the midpoint math Square requires per transition, and real sustain playing rarely lines up with clean midpoints, the point-by-point method from 4.2 is generally the more practical choice for irregular pedal timing: place a point at 127, then a second point one grid increment later at 0, right where you want the release. Repeat this pair for each toggle. Square's midpoint trick is worth keeping as a secondary option when your transitions really do need to land on a precise, calculable beat.
Of course cc data input is much faster and more efficiently done with a controller or a key shortcut mapped to a parameter, but this is an alternative to edit and refine automation. Finally, if you want to redo an envelope, pressing Control+Delete erases the whole automation for a particular cc.


5: Editing audio in arrangement view:

A first concept to retain: Unlike other daws like for example, Reaper or Audacity, in Ableton, you are always working on a timeline.
So, when you move the cursor, the movement is always tied to the way you have your timeline or grid set.
Selecting a portion of audio with Alt+Shift+left or right arrow follows the grid when snapping is on, or the current zoom level when it's off, see section 5.1 for the full detail.
Like the session view, the Arrangement view has two areas that you can move between with escape.
Headers is the area where commands such as solo, s, mute, 0, erase the track, etc. are available.
Time line is the editing area itself.
Clips, whether midi or audio, can only be edited when they are not playing in the session view.
So, if you want to edit a clip, as you will see below, you have to copy or cut it to the Arrangement view.
To move in the arrangement view by measures, or any other grid division set, you use the left and right arrow and the number of that particular grid unit where you are located is announced.
Unlike the session view, in the arrangement view, the tracks are listed vertically.
When you import audio into ableton, by default, it detects the tempo of the project and adjusts the audio at that time.
If you want to avoid this,go to preferences with control+comma, choose the "Record, Warp & Launch" tab, and deactivate the box that says "Auto-Warp Long Samples".
It is always possible to reactivate this option when necessary.
When importing audio, at least from the browser, it is best to press control+c on the desired sample, and then copy it to the right measure, normally the initial measure.
As in the midi editor, it is also advisable, at the beginning, to press escape to deselect the clip or all the material in the arrangement view, if not, instead of editing the clip, you will by default, simply move it in the timeline.
On the track or tracks where you have the audio, Ableton announces not only the clip, but also whether you are at the beginning or end of the clip, when you move with the right and left arrows between measures.
So, for example, if a clip has 16 measures, in measure 1 it announces the beginning of the clip, in 17 it announces the end of the clip.
If the track has only one clip, control and left arrow moves the cursor to the beginning, control and the right arrow moves the cursor to the end of the clip.
If you have more than one clip, control and the left or right arrows move successively from the beginning of the first to the beginning of the next, and in the last clip, to the end of it.
If you want to select just a certain clip, just locate it with control and the left or right arrows, place the cursor at the beginning of that clip and press control+shift+right arrow once.
To select contiguous clips to the right, press control+shift+right arrow as many times as the number of clips you want to select.
To the left, press control+shift+left arrow.
If you move with the left and right arrows and place the cursor at the end of the clip, and then press enter, it will start editing the end of the clip.
Then, pressing the arrow on the right, it will stretch that clip as many bars as you want.
If you press the left arrow, it will shrink the clip in the same proportion.
The same happens if the clip is further inside the time line and you place the cursor at its beginning, and then press enter.
If you use the left arrow, it stretches the beginning of the clip towards the beginning of the time line.
This is very useful when the clip is configured to loop, because it allows the loop to be prolonged as the right end of the clip stretches.
If what you hear is according to your choice, just press enter again and the program indicates that it has stopped editing the beginning or end of the clip.
Of course, if the clip is at the beginning of the time line and you arrow left, it stops at the beginning and does not change.
If instead of enter you press escape, it will not accept the change, it simply says that the editing of the clip has been cancelled.
If you select the clip and want to duplicate it, the command is control+d.
Then another clip will be added after the previous one.
If you have several clips on a track and you want to join them into one,you select several times with control+shift+side arrows, and do control+j.
It is the equivalent of Reaper's glue.
If, on the other hand, you have several clips on a track, and you move to the end of a clip and press enter, it asks if you want to edit the end of the previous clip, or the beginning of the next clip.
If you press left arrow, you will edit the end of the previous clip. If you press the right arrow, you will edit the beginning of the next clip.
Rename a track or clip: Select it and press control+r.


5.1: Selecting audio within the clip:

To select audio within a clip, press alt+shift+left or right arrow. Control+4 toggles grid snapping entirely on or off. Here's the gotcha to remember: with snapping on, the selection actually follows your current zoom level, not the grid. With snapping off, it follows whatever grid division you had set before turning snapping off. So to select by a specific grid value, set the grid first, then turn snapping off.
To hear what's selected, press control+spacebar. With nothing selected, it plays normally from the current bar.
Control+5 switches between a fixed grid and one that adapts to your zoom level.
Z zooms in on your current time selection, down to a single sample if needed, for finer selection. X steps back out one zoom level at a time, and since the selection increment scales with zoom, each step back with X makes each following arrow-key press select more.
Ableton has no start and end marks for a time selection, so it's not as rich as in some other programs, but you can still select extremely small snippets of audio, down to milliseconds, as fine as 1 out of 1024 samples, well beyond what the human ear can hear.
If you make a selection, say with shift and right arrow, and want it to loop, press control+l with the selection made, then play with the space bar.
It's a toggle, so the same command turns the loop on and off.


5.2: Mixing:

The easiest way to level track volumes is to tab through the timeline until you reach the volume control.
From there, control+tab jumps to the next track's volume control, control+shift+tab to the previous one. Adjust with the vertical arrows, or type a value directly, typing a minus sign or hyphen first for a lower value.
The same goes for the pan and solo controls.
Accessibility here still feels rough, either not fully built out yet, or just not very intuitive.


6: Midi Generative Tools:

This tool generates melodies through algorithms, based on a loop.
You'll find it in the clip view, under the Tool tabs group.
To generate a melody:
Step 1: have your loop defined and the clip selected, then press control+l.
Step 2: go to the control bar with alt+0, and set the scale you want, note duration, etc.
Step 3: back in the clip view, tab to tool tabs, then use the side arrows to find Midi Generative tools.
Set the options you want there and click apply.


7: Browser and Device View:

The browser is Ableton's search tool. You access it with alt+5.
This is where you will look for effects, instruments, samples, etc.
Your navigation is always in a tree,and there is a search filter that is accessed with control+f.
When you find the desired instrument, plugin or effect, you can move with the arrow to the right, to see the respective presets, or, in the case of an instrument, you can even hear a preview of each preset.
Midi items, such as midi drum loops, cannot be previewed this way.
When you locate the desired sound or preset, you press enter to insert the plugin into the track.
To access the parameters of this effect, you have to go to another category called Device View, which is accessed with alt+4.
In this category you can see all the plugins that you insert in this track, horizontally, with the respective arrows.
The plugins that you add to the chain are placed to the right of the previous ones.
As in Reaper, it is possible to focus on each of these plugins and delete it, copy it, or change the order of the chain, with windows commands, such as delete, control+c, control+x, control+v.
If the plugin you are using is native to Ableton, its parameters are accessed by exploring the window with the tab key, and adjusting the values with the vertical arrows, or typing with the numbers, without forgetting the minus sign or hyphen when you want to decrease this parameter.
To reset to the default value, use the delete key.
In the case of external plugins, or where the parameters cannot be found with the tab key, the device view shows two combo boxes called Assignable x controls and Assignable Y controls.
Opening these combo boxes you will find the various parameters of the plugin. It is only possible to choose one at a time.
When you choose a certain parameter, it is associated with the respective button, be it x or y.
Then, with shift+tab, you locate the x control buttons, which moves with the horizontal arrows, and the y control which moves with the vertical arrows, and you adjust the values.
A very useful button in the device view is the Hot-Swap Presets button.
When you are in the device view and press this button, it opens the browser immediately, in case you want to look for another preset, or even another plugin.
Another thing to pay attention to is the context menu.
If you are on a parameter button and press the applications key, you can find interesting options, depending on the control that is in focus.
Some of these options make possible to show automation, or map the parameter button to a knob or key on our midi controller.
In general, in the device view, you can press control+m, move to the parameter you want to map, and turn the knob or press the key, to memorize this mapping.
In the device view, you can also group two or more plugins into a rack, or group. Just go to the list of plugins that appears in the device view, focus on the first element, press shift and right arrow to include the next one in the selection, and press control+g. This creates a group or instrument rack.
The advantage of these racks or groups is that it becomes possible to map parameters to macros,and then control these macros using either the keyboard or the controller, having several parameters in a single knob or slider.
This is still not very accessible, but with a few turns, and entering more complex tables, it is doable.
To ungroup or disassemble the rack, control+shift+g.
Suggestion: Search for a rack in the browser, open the device view, and with tab, look for a check box called Show macro controls.
If you select this box, chances are that the macro controls will be displayed.
If you enter Macro Map Mode, a table is displayed with the normal table navigation commands, which is more or less navigable with the NVDA object browser, where you can see the name of the macro elements, and press enter on the desired one.
It is something that is still very, very little accessible, but the important thing is the parameters and their individual controls, and you can adjust those.


8: Audio and mixer automation:

you have a track with something, and you want to automate a parameter, for example, the volume.
The idea is to make a total fade out.
Step 1: In the arrangement view, tab to the track's volume parameter.
Step 2: Press the applications key and arrow down to show automation; enter.
A kind of second track called lane is then created. Focusing on that lane, you can go through the time line according to the grid, and insert the break points.
Step 3: With this new lane selected, you place the cursor at the desired point, and press enter. There the program says that it is inserting a break point.
If applicable, you change the value with the down arrow. If not, there is the first break point that shows 0 db.
With this break point selected, you can also move it on the timeline according to the grid, with the horizontal arrows.
Step 4: Move to the place where you want to insert the next break point, and change the value according to what you want.
In this case, if you want to make a total fade out, just move the button to minus infinity db or type the value.
The result is that an automation curve is drawn between the 2 break points.
With the cursor on the automation lane, you can move with the side arrows, and reading the values progressively descending, until the last break point where the value is at minus infinity.
Each and every parameter is automated in this way.
It is also possible, right from the start, to press the key a, on the desired track. Then perhaps a parameter will appear ready to be automated. If it doesn't appear, you have to go to it, and activate the show automation option as already described.
The automation lane is just one, but you can access all the parameters in it.
To do this, with the lane selected, press control and arrow up or down, and the next parameter is focused.
Let's assume that you have the volume and the pan in the same lane. With the control and vertical arrows, you focus on each of these parameters to carry out automation.
If you want to see which track parameters are or are not visible for automation, in the lane, you press control+shift+vertical arrows, and listen to the name of the parameters, and whether or not they are visible.
If you hear the name of the parameter followed by the indication Not Automated, just press enter there, and the parameter becomes visible and added to the lane to be automated.
This process applies to the track parameters. But what if you want to automate a plugin or effect parameter?
Simple! Just insert this plugin into the track through the browser, and, in the lane, all its parameters will be in the list for you to choose, just like the track parameters.
Alternatively, you can go to the device view, locate the desired parameter, and, with the applications key and arrow down, you will locate Show Automation. Just press enter and you will add another parameter to the lane.
To move between the break points, use control+left arrow for the previous one, control+right arrow for the next one.
If you duplicate the clip, all the automation will also be duplicated, that is, it will integrate the new clip into the timeline.
If you don't want this to happen, on the track where you have the content, press tab, to reach a box that says Lock envelopes.
By default it is unchecked, just check it, and the automation will be locked to the desired clip or clips, and does not move on to the following ones.
Automation can also be done in real time. To do this, you have to go to the Control bar with alt + 0, and check a box that says Automation. This way, you can focus on a parameter, click the record button, and turn the controller's knobs.
To achieve this, it is also necessary that the controller is sending all midi messages to Ableton. Even so, automation, as it has been described so far is more robust and easier to execute.


9: Taking material from the Session view to the Arrangement view:

In order for you to edit a clip that is in the session view, you need to pass it to the arrangement view. Here are the brief steps:
Step 1: In the Session view, move with the right arrow to the area called Scene Launcher.
Step 2: Focus on the desired scene and copy with control+c.
Step 3: Alt+2 to move to the session view, focus on the desired tracks, and control+v to paste.
Step 4: f10 so that the material plays from the arrangement view, and not from the session view.
To go from the arrangement view to the session view, it's exactly the opposite.
If the material does not play in a loop, go to the clip properties with control+3 or alt+shift+p, and with tab, look for Clip Loop, and check it with enter.


9.1: Some isolated random operations:

Create new audio track: control+t

Create new midi track: Control+shift+t.

Create return track: Control+alt+t.

Rename tracks or clips: control+r.
By using this shortcut, you can rename a track or item. If in that same field you press tab,you go to the field to rename the next track or clip.

Create very fast crossfades to eliminate glitches: control+alt+f.

Import a sample to a midi track:, even with the Windows explorer:
Find the sample, control+c, and open the device view with alt+4, and paste.
At this point, Simpler, the Ableton sampler, will open, and the sample you imported becomes available on the keyboard.
To make the sampler play fully, look for a combo box that says Classic, and change it to one shot with the down arrow.

Create an empty midi clip: control+shift+m; the same as adding an empty midi item in Reaper.

Making fade outs is only accessible by making a time selection with alt+shift+right arrow, remembering that it is best to always have the grid adjusted, and press the applications key, the context menu key, also reachable with Shift+F10 if your keyboard doesn't have one, and arrow down until fade out. There, enter.

The warping functions in clip properties are also very interesting to explore.
The various modes allow you to change the audio so that it sounds very interesting.

Split the clip: control+e.

Duplicate all clips in a scene: control+shift+d.
It's useful when you want to do control+j to put everything together in one clip per track.

Render a project: Control+shift+r.

Trigger clips or scenes with a hotkey in session view:
Step 1: Select the clip.
Step 2: Control+k to enter hotkey mapping mode.
Step 3: Press, for example, one of the numbers in the top row, so that each clip or scene corresponds to a number.
Step 4: Again control+k to close the key mapping mode.
This way, each clip or scene is associated with the corresponding number, which, if pressed, will immediately start playing it.

Jump directly to a time or measure in the project:
Step 1: alt+0 for the control bar.
Step 2: Tab to Arrangement position, and, with the slider or by typing the numbers, define where you want the cursor to move.
Exploring the window with tab, other sliders appear that you can use to refine the movement.


10: Punch in and punch out:

This is handy when you just want to fix a mistake in the middle of a clip.
The key is knowing how many bars and beats you want the punch to last.
Step 1: go to the control bar with alt+0.
Step 2: tab to the Arrangement looping grouping.
The first field is the punch in point. Set the start of the punch here, usually the value is already filled in if you stopped the cursor at that point.
Step 3: tab and check the punch in box.
Step 4: tab again and check the punch out box.
Step 5: tab and set how many bars you want the punch to last.
Step 6: set the last two fields, beat and 16th note, then exit the control bar.
Step 7: rewind a bit and start recording. The program plays until the punch in point, starts recording there, and stops recording only at the punch out point.


In recent versions there is a shorter method that does not require setting bars or beats.

  • Step 1: on the desired track, place the cursor at the point where the punch should start.
  • Step 2: select the area to be recorded, using your preferred method, either by grid or by zoom level (see section 5.1).
  • Step 3: press alt+0 to go to the control bar, tab to the punch in and punch out check boxes, and check both.
  • Step 4: press alt+2 to return to the arrangement view and place the cursor one or two bars before the selection, to give some context.
  • Step 5: press f9 to start recording. The program plays up to the selected area and records only inside it. You can record as many takes as you want, and all of them are available for comping.

11. Locators:

Locators are equivalent to markers in Reaper.
To insert a locator in a track, simply tab to the respective button.
To navigate between locators, use the tab or right arrow for next locator, and shift tab or left arrow for previous locator, and enter the desired one.

To work with a locator you already have, go to the Arrangement view and tab past everything else until you hear numbers followed by the word grouping, for example "1, grouping" or "12, grouping". Those are the locators.
Press Shift+F10 on one of them to open its menu, which has these options:

  • Delete
  • Rename
  • Edit info text
  • Loop until next
  • Select until next
  • Set song start time here

There is no direct command to move a locator. To move one, jump to it, delete it from this menu, place the insert marker at the new position, and insert a new locator there with the button. If the locator had a name, rename the new one.


12: Sends:

It is also very easy to create sends in Ableton.
Let's create a send for a vocal track:
Step 1: For the sake of organization, below the vocal track, press control+alt+t to create a return track.
Step 2: Insert the desired effect into this track, be it a reverb, an equalizer, compressor, etc.
Step 3: From the vocal track, tab until you hear the name of the return track you created, which It will normally display a volume of -inf db, and then increase that volume to the desired level. The send has been created.


13: Sidechain:

Let's give some movement to the sound, causing a kick to lower and raise the volume of a bass or pad.
Step 1: Place a plugin that supports the Sidechain parameter, normally a compressor, on the track you want to compress, for example, a bass or a pad.
Step 2: In this compressor, activate the sidechain, and choose the kick track from the external source.
Step 3: Adjust the compressor parameters, so that the play, the kick drowns out the bass or pad, and when the kick stops being heard, the pad rises again.


14: Making hi-hat rolls:

This applies to any instrument, since it's really about the midi editor.
You can do it in either arrangement view or session view.
Step 1: with the instrument or sample loaded in a midi clip in the midi editor, quantize the notes first on a wider grid, say 1 by 4.
Step 2: if you're in session view, put the sample in play mode.
Step 3: set the grid to 1 by 4 and quantize.
Step 4: insert the notes, matching their size to the grid.
Step 5: narrow the grid, to 1 by 16 or 1 by 32.
Step 6: select the notes you want to split, one after another, and press control+e to chop them in increments of 1, or control+shift+e to chop them in increments of 2.
You can repeat this, narrowing the grid further each time.


14.1: Advanced rhythm programming:

Besides the midi generative tools, Ableton has other algorithms for programming rhythmic patterns you might not have thought of.
Let's talk about Rhythm Generator.
You can play or program with it in whatever way works best for you.
Here's a suggestion to get the main idea across before diving into the rhythm generator.
Step 1: load the drum kit you want.
Step 2: control+shift+m to insert an empty midi clip.
Step 3: alt+3 to the midi editor, and set the grid the way you want.
Step 4: insert the kick note, using a midi or pc keyboard, while pressing the right arrow at the same time.
This places the note into the right spots on the grid.
Make any grid adjustments before inserting the note, not after.
Step 5: in the midi editor, tab until you hear Tool tabs, pitch and time utilities.
Step 6: in the same spot, arrow right until Midi generative tools.
Step 7: tab to Rhythm.
You'll get a list of available sample names. Press enter on the one you want. Hit play and the sound plays inside the rhythmic pattern you built.
Step 8: use tab and the arrows to explore the different options and hear the result.
To add more sounds, press escape to deselect the current notes, click Reset, go back to the list from step 7, and repeat the process, since the algorithm places notes based on whatever parameters you set.
You can of course keep editing normally too, combining the rhythm generator with the midi editor for more creative results.


15: Knowing the tempo of a song in bpm

It's not foolproof, especially if the song is old and wasn't recorded to a metronome.
Step 1: In the preferences, on the Record tab, warp and launch, with tab, look for a box that says Autowarp long samples, check if it's unchecked.
Step 2: One more tab, and Warp mode appears. By default it is in beats, set it to complex.
Step 3: Import the song. Copy the audio file from Windows Explorer, then paste it into the track. Wait a bit while Ableton analyzes it.
The song will have the project's default beats, normally 120. Then:
Step 4: With the clip selected, enter the clip view with alt+3, and tab until you hear Audio Utilities, and tab again until tempo lead or follow. Choose lead and when playing, the metronome tempo is adjusted to the music.
you will also find a field there with a number followed by the indication seg bpm, which corresponds to the number of beats in the song.
Step 5: With this number, you can go to the control bar and type it or paste it into the box that shows the project tempo.


16: Contiguous and non-contiguous track selection:

It's not something you'll miss much, mostly useful if you like keeping tracks organized, or need to group non-contiguous tracks.
To group contiguous tracks, select them with shift and the vertical arrows in arrangement view, or the horizontal arrows in session view, then press control+g.
You can then name the resulting group or folder.
This group sits in a tree too: to open it, focus the name and press u to unfold or fold the folder.
It works exactly like track folders in Reaper.
If the tracks aren't contiguous, locate each one, press control+x to cut it, open the group, and control+v to paste it in.
You can also move a track up or down the list with control and the up or down arrow in the headers section of arrangement view, or control and the left or right arrow in the headers section of session view.
That way, even non-contiguous tracks end up together in the group.
To ungroup, press control+shift+g.


17: Slice to midi track:

Especially for those who like working with samples, it is a very valid resource. From an audio file, for example, a drum recording, it is possible to divide it into transients, beats, quantized notes, and map these successive divisions to the keyboard. Plus, with the advantage of everything being placed on a midi track, you can use the midi editor to work with these pieces of audio.
If you have a drum loop, for example, make sure the clip has warping enabled first, otherwise the slice option stays greyed out. With the clip selected in the Arrangement View, you can either right-click it and arrow down to slice to new midi track, or use the Create menu at the top of the screen and choose the same option. A dialog opens with the following controls:

  • Splitting resolution combo box: bar, quarter note, half note, at transients, and so on.
  • Algorithm combo box: drums, vocal, and so on.
  • Preserve warped timing checkbox.

NVDA reads all three controls fine, but their labels aren't announced, so you need to know the order above to tell them apart.
After applying the process, you will be left with the samples distributed across the keyboard. A rack is created in the device view, where you can see the various samples and some macros. Opening the device view puts focus on the clip's name followed by Drum Rack.
From there, pressing a midi key selects that pad, and on Windows using NVDA object navigation, moving to the next object, lands you on a Slice grouping for it, for example Slice 1, Sampler. This supplements regular tab navigation rather than replacing it, and you can also use a connected midi keyboard to select pads the same way.
Within a slice's grouping, a tree/table appears that shows the different ways in which you can play the sample. On Mac the table is navigable and readable; but on Windows, when you use the table commands, you don't get any feedback from NVDA. However, if you scroll through the various data items with the vertical arrows, as you will probably hear, it will say: Data item selected, but it doesn't say what item. If you press enter on that data item, it assumes the way you want the sample to play.
Continuing to navigate from there, with either NVDA commands or regular navigation, you will find clearly identified parameters that allow you to configure how the sample is played: as a loop or as a one shot, the ADSR envelope, volume, pan, the key used, and other parameters such as speed, rate, attack, decay, release, etc. Everything is accessible and easily workable.
Now, as this is an Ableton rack, and each sample is in a slot, it is possible to access effects, copying from the browser with control+c, and pasting it into the rack, always to the right of the respective sample.


18: Reading and managing volume:

In Ableton, reading and managing volume isn't as straightforward as in other daws.
The program's interface is very visual, so getting plain text information out of it can be difficult.
Even so, you can read volume levels, starting with the track list.
Activate the mixer with alt+shift+m, then tab or shift+tab until you hear track volume. That gives you the fader level, normally 0 db by default.
In the same spot you get the peak indicator, showing the track's volume in peak readings.
Here's the catch: natively you can only read peak values, not lufs or rms.
For that, there's a Max for Live device called Flufs, which once installed lets you read lufs and rms in an accessible way.
The main shortcuts are control+shift+v to turn on the device's narration, then shift plus a digit in the number row to read each value in turn. Search for Max for Live Flufs for more information.


19: Max for Live Devices:

Like most programs of this type, Ableton has a community that builds add-ons for it.
These are called Max for Live devices.
You'll find instruments, effects, and other plugins made this way, either on Ableton's website or spread across the internet.
Accessibility here is still hit or miss, but some of these devices are accessible, depending on how they were designed.
They're files with the .amxd extension, and easy to install.
By default, you can just copy them into the Ableton user library, under Presets, Instruments, Audio effects, Max Audio Effect for effects, or Max Instrument for instruments.
You can also place them in other folders, as long as the program knows where to look.
Once installed, they show up in the browser the next time you start the program.


20: Accessibility issues:

Several accessibility and usability problems come up, but most of them have a fairly reliable workaround.
Even so, they can make the learning curve a bit steeper, and slow you down, since you end up doing extra steps to get around them.

Problem: information locked in the graphical interface.
Ableton leans heavily on graphics and very specific visual layouts, which makes it harder for a screen reader to communicate what's happening, even with built-in OCR.
Solution: for text windows or controls that are hard to reach, an AI-based OCR tool such as View Point can help a lot, especially with certain plugins, virtual instruments, or Ableton's own features.

Problem: losing focus.
When switching between areas like session view, arrangement view, or clip view using alt plus a number key, you sometimes get told a command is unavailable, or that you can't record or edit right away.
Solution: try switching to an adjacent area and back to the one you want. It's annoying, but it usually gets the focus back.

Problem: accessibility in device view (alt+4).
This is where you reach plugin racks and their parameters. Often, after loading a plugin or instrument and pressing alt+4, tabbing through says the commands or parameters are unavailable.
Solution: if NVDA doesn't announce the plugin or instrument's name when you press alt+4, focus landed in the wrong place. Try pressing left arrow first. If NVDA then says the plugin or instrument's name, focus is where it should be, and you can tab through its parameters normally. If you still get nothing, reload the plugin or instrument onto the track, go back to device view with alt+4, and try again. It usually works on the second attempt.

Problem: cursor freezing when moving between tracks.
Some plugins or instruments freeze the cursor when you pass over their track.
This is usually caused by a popup window from the plugin, embedded inside Ableton's own window, that NVDA can't read or detect.
Solution: try OCR or the object browser to find the popup's Close button. An easier fix is alt+f4 repeatedly until you're asked whether to save changes, then escape to return to the track list, where the popup is gone.
